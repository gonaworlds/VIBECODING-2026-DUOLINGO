# [PRD] AI 마이크로 툴 & 템플릿 빌더 포트폴리오

## 1. 개요 및 비전
- **서비스 정의**: AI(Figma + Cursor + Vanilla JS)를 활용해 소상공인/1인 창업가를 위한 반응형 모바일 랜딩페이지 및 인터랙티브 웹 툴을 빠르고 경제적으로 제작해주는 프리랜서 포트폴리오 사이트
- **핵심 가치**: 모바일 최적화, 빠른 제작 속도(3~5일), 합리적인 비용, 실제 동작하는 결과물 중심의 신뢰 제공
- **타깃 사용자**: 
  - (외주 고객) 예약/홍보 페이지가 필요한 동네 카페/피트니스 원장, 1인 창업가
  - (에셋 구매자) 노코드/로우코드 템플릿을 찾는 개인

## 2. 핵심 유저 여정 (Core User Journey)
1. **유입 및 첫인상 (Hero Section)**: "모바일에서 가장 예쁘게 열리는 1인 브랜드 랜딩페이지를 만듭니다"라는 명확한 메시지와 Call To Action(문의하기/작업물 보기) 확인
2. **서비스 및 강점 확인 (Services)**: 반응형 웹, 빠른 배포, 합리적 비용 등 차별화 포인트 인지
3. **작업물 검증 (Portfolio Showcase)**: 
   - 헬스장/필라테스 예약 랜딩페이지
   - 카페 팝업스토어 소개 페이지
   - 인터랙티브 웹 계산기 (예: 프리랜서 실수령액 계산기)
   - 각 작업물의 Figma 목업 이미지와 실제 동작하는 라이브 링크(Vercel/Netlify) 확인
4. **프로세스 이해 (Process)**: 기획/Figma 시안 -> AI 코딩 -> 배포 및 수정의 직관적인 작업 흐름 파악
5. **문의/결제 (Contact)**: 오픈 카톡, 구글 폼, 또는 크몽/숨고 프로필로 이동하여 견적 문의

## 3. 핵심 기능 요구사항
### 3.1 메인 포트폴리오 페이지 (One-Page)
- **반응형 레이아웃**: 모바일(가장 중요), 태블릿, 데스크톱 뷰포트 완벽 대응
- **인터랙션/애니메이션**: 
  - 스크롤에 따른 페이드인/슬라이드 업 효과 (Vanilla JS)
  - CTA 버튼 호버/클릭 시 물리적인 눌림 효과 (CSS)
- **Showcase 갤러리**: 클릭 시 해당 프로젝트의 상세 정보 모달 또는 라이브 링크 새창 열기

### 3.2 서브 프로젝트 (작업물 예시 - 향후 추가)
- **프로젝트 A (랜딩페이지)**: 폼 입력 및 유효성 검사 기능 포함 (JS)
- **프로젝트 B (계산기)**: 실시간 DOM 업데이트를 통한 결과값 출력 (JS)

## 4. 비기능적 요구사항
- **성능**: 이미지 최적화 및 경량화(WebP 등)로 로딩 속도 1초 이내 달성
- **SEO/접근성**: 시맨틱 HTML 태그 사용, 명확한 Title/Description 설정
- **유지보수성**: Cursor AI가 쉽게 이해하고 수정할 수 있는 구조화된 HTML/CSS/JS 코드 유지
